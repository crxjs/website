## Install Dependencies

::pm-install{name="vitest-environment-web-ext" save-dev}
::

## Configure Vitest

:::code-group

```ts [vitest.config.ts]
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    environment: 'web-ext',
    environmentOptions: {
      'web-ext': {
        path: './dist',
      },
    },
  },
})
```

:::


## Type Definitions

To enable better type checking and IntelliSense, you need to configure the types.

```json [tsconfig.json]
{
  "compilerOptions": {
    "types": ["vitest-environment-web-ext/types"]
  }
}
```



## Update `package.json`
```json{3} [package.json]
{
  "scripts": {
    "test": "vitest"
  }
}
```

## Write Tests

:::code-group

```ts [test/extension.test.ts]
import { expect, test } from 'vitest'

test('popup should display correctly', async () => {
  const popupPage = await browser.getPopupPage()

  const title = await popupPage.title()
  expect(title).toBeTruthy()
})
```

:::

## Run Tests

::pm-run{script="test"}
::
