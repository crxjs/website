## 安装依赖

::pm-install{name="vitest-environment-web-ext" save-dev}
::

## 配置Vitest

```ts [vitest.config.ts]
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    environment: 'web-ext',
    environmentOptions: {
      'web-ext': {
        path: './dist',
      },
    },
  },
})
```

## 类型定义

为了获得更好的类型检查和智能提示，您需要配置类型。

```json [tsconfig.json]
{
  "compilerOptions": {
    "types": ["vitest-environment-web-ext/types"]
  }
}
```

## 更新`package.json`
```json{3} [package.json]
{
  "scripts": {
    "test": "vitest"
  }
}
```

## 编写测试

:::code-group

```ts [test/extension.test.ts]
import { expect, test } from 'vitest'

test('弹出窗口应正确显示', async () => {
  const popupPage = await browser.getPopupPage()

  const title = await popupPage.title()
  expect(title).toBeTruthy()
})
```

:::

## 运行测试

::pm-run{script="test"}
::
